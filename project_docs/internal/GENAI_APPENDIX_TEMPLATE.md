# GenAI Appendix Template

Use this template only if the team later recovers more concrete prompt evidence.

## Important Note

- Do not fabricate raw screenshots.
- If the team does not recover original chats, keep using the reconstructed appendix in `project_docs/final/GENAI_APPENDIX_RECONSTRUCTED.md`.

## Optional Appendix Structure

### Team Member

- Who used the tool

### Tool / Platform

- Example: ChatGPT, Gemini, Claude, etc.

### Date or Approximate Timeframe

- Example: proposal stage, report-writing stage, presentation-prep stage

### Prompt Summary

- Short summary of what was asked

### Artifact Link, If Available

- Screenshot path, exported chat path, or note that no artifact survives

### How It Helped

- Planning
- methodology framing
- report structure
- pseudocode organization

### What Was Actually Used

- Short note distinguishing adopted ideas from discarded ideas

### Honesty Check

- Confirm whether the record is:
  - original screenshot
  - original export
  - reconstructed from recollection
